# Global instructions

Before any public or outward-facing action, in any project (GitHub issues, PRs, or comments; pushing to a repo I don't own or a shared remote; posting to any external service), show me the exact content and wait for a direct, separate "yes" — implied approval or an AskUserQuestion selection never counts, because publishing is often irreversible. Local, reversible work (commits, branches, builds, pushes to my own fork) needs no confirmation.
